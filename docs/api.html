GymCoach API (1.0.0)

Download OpenAPI specification:

API de GymCoach para gestionar clientes y rutinas. Las rutas protegidas requieren un token Bearer obtenido en POST /login; los permisos se aplican por rol.

integer [ 1 .. 7 ]

string (EstadoRutina)
