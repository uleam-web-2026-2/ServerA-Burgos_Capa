Guarda aquí capturas tomadas al ejecutar la API y las pruebas localmente. No se incluyen imágenes simuladas porque deben mostrar respuestas reales de este repositorio.

Incluye una captura por cada petición de demostración (401, login 200, consulta 200, permiso 403, cambio válido 200 y transición prohibida 422) y una de `go test ./...` en verde. Puedes nombrarlas `01-sin-token.png` hasta `06-transicion-prohibida.png` y `07-go-test.png`.
