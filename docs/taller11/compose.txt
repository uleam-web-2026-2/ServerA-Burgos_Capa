## Validación HTTP adicional en la rama `taller11`

La imagen de la rama se construyó correctamente. Para no interferir con otros
proyectos, Compose se ejecutó con el nombre aislado
`gymcoach-taller11-validation` y un `.env.compose` local ignorado por Git.
PostgreSQL quedó `healthy`; la API se publicó en `18080` porque Windows ya
tenía un listener PostgreSQL en el puerto `8080`.

Las seis peticiones contra `http://127.0.0.1:18080` devolvieron:

```text
401, 200, 200, 403, 200, 422
Petición 5: estado en_progreso
Petición 6: error transicion_prohibida
```

La rutina de prueba se creó dentro del volumen aislado del proyecto de
validación. No se usaron ni modificaron datos de otra base.
