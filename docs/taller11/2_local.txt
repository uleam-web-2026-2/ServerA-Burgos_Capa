# Prueba local de conexión a PostgreSQL

Comando probado:
`go run .`

Configuración local:
- `.env` existe y no está versionado ni copiado en esta evidencia.
- `DATABASE_URL` usa el host `localhost`, el puerto `5432` y la base `gymcoach`.
- `PUERTO=8080`, `TIEMPO_ESPERA_SEGUNDOS=5`.
- Docker Desktop no estaba disponible durante esta comprobación.

Resultado real:
- `localhost:5432` no respondió.
- IPv6 (`[::1]:5432`) y IPv4 (`127.0.0.1:5432`) rechazaron la conexión.
- La aplicación terminó con código de salida `1`.
- No hubo migraciones ni siembra porque GORM no pudo establecer la conexión.

Se comprobó el error `connection refused` correspondiente a una base no
alcanzable; no se usó la contraseña ni se consultaron datos de ninguna base.
Para superar esta comprobación debe iniciarse Docker Desktop y `gymcoach-db`,
usar el puerto publicado por ese contenedor y volver a ejecutar `go run .`.
